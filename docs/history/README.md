# Abhyas design history

These are planning documents from before and during the backend build. They're
kept because they record *why* things are the way they are (no database, no
WordPress, quarantine-then-approve). They do **not** describe the current
state, so use the root `README.md` and `HANDOVER.md` for that.

| File | What it is |
|---|---|
| `backend.md` | First backend proposal, written for adversarial review |
| `BACKEND-PLAN-v2.md` | Revised plan after review. Supersedes `backend.md`. |
| `AGENT-PLANS.md` | Seven models given the same brief, compared and scored |
| `BACKEND-PLAN-v3.md` | The settled plan (Phases 1–3) plus the Phase 4 submission/moderation build |
| `roadmap.md` | The phase checklist used during the build |
